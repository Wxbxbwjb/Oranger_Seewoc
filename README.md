## ✨ 概览

Oranger_Seewoc 是一个针对希沃(Seewo)一体机的批处理脚本工具集，提供了一系列便捷的命令来控制和管理设备功能。

## 💻 功能

- [x] 启动希沃服务
- [x] 停止希沃服务
- [x] 显示CLI版本信息
- [x] 启动ClassIsland
- [x] 停止ClassIsland
- [x] 电源管理（.....）
- [x] 简化希沃服务
- [x] 希沃冰点冻结窗口

## 命令行使用


Oranger_Seewoc_CLI
```batch
echo Available commands:
echo   -en       start seewo
echo   -dis      stop seewo
echo   -v        show version
echo   -cil      start classisland
echo   -kcil     stop classisland
echo   -power    set power
echo   -us       seewo-update-new-simplify
echo   -sf       seewo-freeze-startup-with-main-window
```
